# Mentions légales et aspects juridiques

Ce document accompagne les pages « Mentions légales », « Politique de confidentialité » et « Conditions d'utilisation » du site (adresses `/legal/mentions`, `/legal/confidentialite`, `/legal/conditions`). **Il n'a pas été relu par un juriste** : avant toute exploitation commerciale, un professionnel du droit congolais doit le valider.

## 1. Statut du projet

Mon Miam Miam est un projet intégrateur réalisé par des étudiants à Kinshasa. Il n'est pas exploité par une société. Si le service devient commercial, il faudra créer une structure juridique et compléter les mentions légales : dénomination, forme, adresse du siège, numéros d'immatriculation, responsable de publication, hébergeur.

## 2. Données personnelles collectées

| Donnée | Pourquoi | Qui la voit |
|---|---|---|
| Nom, e-mail, téléphone | identifier le compte, joindre la personne pour une livraison | le compte, les restaurants dont la personne est cliente (nom et téléphone pour une commande) |
| Mot de passe | se connecter | personne : il est conservé sous forme hachée et n'est jamais renvoyé |
| Adresse de livraison, commune, quartier | livrer une commande | le restaurant concerné |
| Commandes, points, réclamations | fonctionnement du service | l'étudiant, le restaurant concerné |
| Code de parrainage, filleuls | programme de parrainage | l'étudiant ; les noms des filleuls sont abrégés (« Marie K. ») |
| Participation aux classements | top 10 des clients | les autres clients du même restaurant, avec un nom abrégé |

Aucune donnée n'est vendue ni utilisée pour de la publicité. Le site n'utilise **aucun cookie de suivi** : il garde dans le navigateur la connexion, le panier et le choix fait sur la bannière.

## 3. Droits de l'utilisateur

| Droit | Comment l'exercer dans l'application |
|---|---|
| Accès et portabilité | **Mon profil**, bouton « Télécharger mes données » : fichier JSON avec le compte, les commandes, les points, les réclamations et les filleuls (noms abrégés) |
| Effacement | **Mon profil**, bouton « Supprimer mon compte », avec confirmation par mot de passe. Le compte est **anonymisé** : nom, e-mail, téléphone, adresse et textes personnels sont effacés, les points restants sont abandonnés. Impossible tant qu'une commande est en cours |
| Rectification | contacter l'équipe ; une page de modification du profil n'est pas encore disponible |
| Changer de mot de passe | **Mon profil**, ou « Mot de passe oublié » depuis la connexion |

Les montants et les dates des commandes sont conservés après suppression, sans nom, pour la comptabilité des restaurants.

## 4. Sécurité

Mots de passe hachés, jetons signés qui deviennent invalides après un changement de mot de passe ou une désactivation, isolation stricte entre restaurants (le restaurant vient toujours du jeton), images PNG, JPEG et WebP uniquement (pas de SVG), en-têtes de sécurité HTTP, limitation des essais de connexion.

## 5. Conditions d'utilisation (résumé)

Compte unique pour tous les restaurants ; commande validée après le paiement choisi ; points propres à chaque restaurant avec les règles affichées sur la page Mes points ; réclamations examinées par le restaurant ; usage abusif (fausses réclamations, parrainages fictifs) pouvant entraîner la suspension du compte.

## 6. À compléter avant une ouverture au public

- Identité de l'exploitant et de l'hébergeur dans les mentions légales.
- Contact pour exercer ses droits (adresse e-mail de l'équipe).
- Durée de conservation des données et procédure de notification en cas de fuite.
- Conditions de remboursement d'un paiement mobile money.
- Relecture par un juriste.
